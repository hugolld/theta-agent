# Theta research loop (stub)

This is a placeholder for the full co-researcher skill set. The M1 milestone
replaces this directory with the curated Tier-1 library (literature review,
hypothesis generation, experimental design, statistical analysis, scientific
writing, critical thinking).

## Intended loop

1. **Frame** — restate the research question; identify success criteria
2. **Search** — literature lookup; note prior art and gaps
3. **Hypothesize** — propose testable, falsifiable hypotheses
4. **Design** — plan the analysis or experiment; pick methods and data
5. **Execute** — run code/analysis; record provenance of every step
6. **Report** — results with uncertainty, limitations, and citations
