Our group is starting a small study on how co-administering direct oral anticoagulants with nonsteroidal anti-inflammatory drugs affects bleeding risk in older adults, and the literature needs narrowing first. Search recent research literature for primary studies on that question, keep only what actually bears on it, and record what you kept for the project so a later session can build on it -- include the specifics of each kept source: what it showed and how to retrieve it again. Run each shell command as one plain command: chain steps with && only, never a semicolon or a trailing status echo. Before you rely on any instruction or reference file, read it whole in a single call, with a limit larger than its line count -- never an exact-count or fragmented read.
